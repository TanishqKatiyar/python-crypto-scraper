# Decentralized Endpoint Crypto Scraper

An automated data pipeline utilizing Pandas and Requests to extract, frame, and analyze live cryptocurrency market caps and metrics via external REST APIs.

## Setup
1. Clone the repository.
2. Ensure you have pip initialized:
```bash
pip install -r requirements.txt
```

## Running the extraction node
```bash
python scraper.py
```
Outputs parsed analytical frameworks directly into local `csv` logs.
